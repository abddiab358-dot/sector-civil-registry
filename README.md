# السجل المدني لثلاثة قطاعات

نظام أكاديمي لتسجيل السكان والوثائق المدنية: ثلاثة قطاعات تحت إدارة مركزية، مع دفاتر عائلة وولادة ووفاة وزواج وطلاق وهوية وإحصاءات مربوطة بالسجلات الحية.

## التشغيل

```bash
npm install
npx prisma db push
npx prisma db seed
npm run dev
```

ثم افتح `http://localhost:3000`.

ملف البيئة المحلي `.env`:

```
DATABASE_URL="file:./dev.db"
AUTH_SECRET="crs-academic-demo-7f3a9c2e4b81d06a"
```

## القواعد

- موظف القطاع لا يقرأ ولا يكتب خارج قطاعه. الفحص يتم في الخادم.
- الولادة تنشئ فردًا ورقمًا وطنيًا وشهادة، وتضيفه إلى دفتر الأب إن وُجد وإلا تفتح دفترًا. تُرفض إذا توفي أحد الوالدين قبل التاريخ، أو كان العمر وقت الولادة غير منطقي.
- الوفاة وثيقة واحدة: تُلغي الهوية السارية، وتُحوّل الزوج الآخر إلى أرمل أو أرملة.
- الزواج لبالغين أحياء غير متزوجين، وليسا أصلًا أو فرعًا أو إخوة. الزوجة تنتقل إلى دفتر الزوج، أو يُفتح دفتر جديد إن لم يكن رب أسرة.
- الطلاق لعقد قائم فقط، ولا يتكرر.
- الهوية للأحياء. التجديد يلغي السابقة.
- نقل الإقامة للإدارة المركزية. الوثائق تبقى صادرة من قطاعها الأصلي.
- الإحصاءات تُحسب من جداول الأشخاص والوقائع.

أرقام وطنية تجريبية تبدأ من `1900000001`. جاد عبود ولين يوسف بلا هوية لتجربة الإصدار.
